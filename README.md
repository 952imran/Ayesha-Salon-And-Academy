# Ayesha Salon & Academy — Web Platform & LMS Portal

Official web portal and online beauty academy LMS software for **Ayesha Salon & Academy**, located in Kausa Mumbra, Thane.

## 🌟 Key Features
- **Luxury Mobile-First Branding**: Royal Rose-Gold & Dark Gold theme.
- **Paid Video Masterclass LMS**: Secure video streaming arena with 30-day access expiry & Lifetime VIP Pass.
- **Dynamic Anti-Piracy Watermark**: Canvas overlay displaying student name + phone number.
- **Luxury Certificate Generator**: One-time verified student name locking with verification ID.
- **2-Tier Admin & CRM Portal**: Separate roles for Salon Manager & Super Developer.
- **Free Showcase & Reels**: Smart YouTube, Instagram Reels, and direct video file uploads.
